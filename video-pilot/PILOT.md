# Video pilot: start small, then decide how big to go

Written 2026-11-20. Spends nothing until you run it. Prompts are generated by `build_prompts.py` (deterministic) into `prompts.jsonl`; results go in `scoring-sheet.csv`.

## What the pilot must answer
1. Which theme gives clips you would approve most often?
2. Which exercise types does video handle (standing, seated, lying, kneeling, a doorway prop, a small hand motion) and which does it not?
3. What is the approval rate p? Clips needed for the full 189 is about 3 / p per exercise (p = 20% gives about 2,650).
4. Which model, and is the GPU worth renting for the full run?

## The matrix
6 exercises x 4 themes x 4 takes = **96 clips** (24 unique prompts).

| Exercise (id) | Position | Why it is in the pilot |
|---|---|---|
| overhead-side-bend | standing | easy baseline, no props, left/right matters |
| neck-side-bend | seated, chair | small head motion, a prop, fine side control |
| supine-hamstring | lying | floor pose, hands behind the thigh |
| kneeling-hip-flexor | kneeling | floor pose, one knee down |
| doorway-pec | standing, doorway | a prop the model must place correctly |
| median-gentle-slider | seated, glide | hardest: small wrist, finger and head motion |

Themes: **studio-dark** (matches your app), **studio-light**, **flat-illustration**, **wooden-mannequin**. The theme block is the only thing that differs between the four prompts of one exercise, so any difference in approval is down to the theme.

## Run order (inside the pilot, also small to big)
1. **Round 1: one theme, one cheap model.** studio-dark x 6 exercises x 4 takes = 24 clips on the cheapest model. Score them. Fix prompt wording (the visual scripts are my drafts from your steps, so check the left/right wording first). Re-run only what you changed.
2. **Round 2: all four themes** with the improved wording, same model: 96 clips in total.
3. **Round 3: a second, stronger model** on the best two themes only (48 clips).
4. If consistency is the main failure, a **fixed start image with image-to-video** on the best theme (24 clips).

## Score every clip (`scoring-sheet.csv`)
Mark each criterion yes or no, then record review seconds.

| Column | Criterion |
|---|---|
| side_ok | The correct limb and direction (right arm up, lean left, and so on) |
| poses_ok | Start and end positions match the visual script |
| setting_ok | Chair, mat or doorway present and used correctly |
| motion_ok | The motion is the stretch, not some other movement |
| artifacts_ok | No extra or merged limbs, no mangled hands at normal viewing size |
| framing_ok | Full body in frame, static camera, one person |
| paced_ok | Calm pace, ends near where it began (loops cleanly), desirable but not required |

**approvable = the first six all yes.** Anything the clip shows that the steps do not say is a fail.

## Decision rules (decide before you look at results)
| Result | Decision |
|---|---|
| A theme has at least 25% approvable overall and at least 4 of 6 exercises with at least one approvable take | That theme scales to the full 189 |
| An exercise type has 0 approvable across all themes and models | Route that type to the pose-spec plan, not video |
| Overall approvable is under 10% | Video is not the main route. Use the pose-spec plan, and use video only as a reference |
| Between 10% and 25% | One more round with image-to-video and prompt fixes on the best theme, then reassess |
| Reviewing takes over 20 s per clip | Add the automatic pre-filter before any bigger run |

Full-run clip count = 189 x themes x (3 / p). Compute it from the measured p, not from this document.

## Log for every clip
